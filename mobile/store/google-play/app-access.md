# Review access and safety operations

Launch the connected release and start as a guest. No reviewer account is needed to reach chat. Optional signup/sign-in is available. Shared AI and guest-session limits apply: verify sufficient allowance before review; never disable abuse protection indiscriminately.

Review journey: open Leo → send a message → view reply → Report → select category → submit. Open Account → Privacy and your data. For deletion, use a disposable account/workspace: Account → Delete account/workspace → type DELETE → confirm.

Reports are available to configured backend administrators at GET /api/admin/reply-reports. Access is closed when admin_accounts is unset. Before release, configure an operator, verify authorized review and establish a regular review/remediation process. Never place admin credentials in the app or this folder.

Use non-sensitive demonstration content and accounts. Do not give reviewers production owner credentials.
