## Reproducing locally

From the current repository, create/use a Python 3.12 venv. Install runtime packages with `uv pip install --python backend/.venv/bin/python --require-hashes --no-deps -r backend/requirements.lock`, then the tools from backend/requirements-dev.txt. Run backend commands from backend/ so configuration and migrations resolve correctly. Use `npm ci` in frontend/, then typecheck/lint/build and the portable checks. Keep private env files outside source control; use SQLite/mock for isolated development or explicitly provide a local PostgreSQL instance and run `alembic upgrade head`.

For production-stack verification follow deploy/tests/production-rehearsal/README.md. It uses the actual Dockerfiles, Caddyfile and migrations with disposable data and a scripted upstream. Never point those destructive rehearsal operations at production data. Real provider quality, public DNS/TLS, physical off-host storage and operator schedules require deployment-specific evidence.
